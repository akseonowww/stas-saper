# Стас-сапёр XP

Сатирический браузерный сапёр: публикуйте ролики, вычисляйте модераторов и спасайте канал. Аккуратная оболочка в духе Windows XP, адаптация под экран телефона и компьютера.

## Запуск
Откройте index.html или включите GitHub Pages для ветки main, папки / (root). Сборка и зависимости не нужны. На HTTPS доступны service worker и манифест для запуска с главного экрана. После первого успешного открытия основные файлы доступны офлайн; внешние GIF требуют интернета.

## Правила
Поле 9×9, уровни с 10, 15 и 20 модераторами. Первый ход и его соседи безопасны. Откройте все клетки без мин. Цифры показывают число мин среди восьми соседей. Генерация не гарантирует решение без угадывания.

Нажатие открывает клетку. ПКМ или удержание на телефоне ставит флажок, также есть отдельный режим флажков. Нажатие на открытую цифру открывает остальных соседей, если количество флажков совпадает с цифрой. Ошибочный флажок может привести к проигрышу. Клавиатура: стрелки, Enter/пробел, F/А для флажка.

Три подсказки на партию отмечают безопасные клетки и отключают запись рекорда. Рекорды хранятся локально отдельно для каждого уровня. Серия растёт при успешных ходах с интервалом менее 3,5 секунды. Таймер продолжает идти при переключении вкладки.

## Звук и мемы
Встроенные оригинальные эффекты синтезируются Web Audio: открытие, массовая публикация, флажок, старт, бан, победа. В настройках можно включить обычный системный голос (это не голос Стаса), отключить GIF или выбрать собственные звуковые мемы для бана и победы. Выбранные аудиофайлы никуда не загружаются и действуют только в текущей вкладке.

GIF встроены внешними ссылками Tenor и могут быть недоступны в отдельных сетях; предусмотрена запасная реакция. При системной настройке уменьшения движения анимации и GIF отключены.
