# Стас-сапёр

Сатирический сапёр в интерфейсе видеостудии. Публикуйте ролики, вычисляйте модераторов, спасайте канал.

## Запуск
Откройте `index.html` в браузере. Сервер, сборка, аккаунт и зависимости не нужны. Игра работает без интернета.

## GitHub Pages
Загрузите `index.html` и `.nojekyll` в корень репозитория. В настройках репозитория включите Pages с публикацией из ветки, содержащей эти файлы, из корневой папки. GitHub покажет адрес после публикации.

## Управление
Нажатие открывает клетку. Правый клик или режим «Не публиковать» ставит флажок. Клавиатура: Tab для перехода, стрелки по полю, Enter/пробел для открытия, F/А для флажка.

Поле 9×9, уровни с 10, 15 и 20 минами. Первый ход и его соседи безопасны. Откройте все клетки без модераторов для победы. Флажки не гарантируют правильность выбора. Генератор не гарантирует решение без угадывания.

Все ролики и блокировки вымышлены. Проект не связан с YouTube или Стасом. Внешние материалы, изображения и трекеры не используются.
