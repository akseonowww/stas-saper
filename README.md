# Стас-сапёр XP v3

Сапёр в оболочке Windows XP с игровым YouTube-каналом. Работает на телефоне и компьютере без сборки.

## Игра
Поле 9×9, уровни с 10, 15 и 20 минами в меню «Игра». Первый ход и его соседи безопасны. ЛКМ открывает клетку, ПКМ или удержание на телефоне ставит флажок. Есть отдельная кнопка флажков. Нажатие на открытую цифру открывает остальных соседей, если количество флажков соответствует цифре. Неверные флажки могут привести к проигрышу. Стрелки перемещают фокус, Enter открывает, F/А ставит флажок.

## Рост канала
Каждая безопасная клетка — ролик. Первый получает 100 просмотров. База следующего растёт на 50% (с округлением), до 1 000 000 просмотров. Каждый десятый ролик получает ×10 к своей базе; этот бонус не умножает базу следующих роликов. 5% суммарных просмотров превращаются в подписчиков, с округлением вниз. При автоматическом открытии области учитываются все открытые безопасные клетки.

Рекорд по подписчикам сохраняется в localStorage после каждого хода, в том числе перед проигрышем. При создании нового канала текущие показатели сбрасываются, рекорд остаётся. Время не влияет на результат. Подсказки, серии и рекорды времени удалены.

## Реакции
На новые ролики чередуются GIF «вау» и одобрения; на вирусные ролики и рекорд — удивление; на бан — отдельные реакции; на победу — одобрение. GIF показываются кратковременно, затем исчезают. При массовом открытии очередь ограничена пятью недавними событиями, чтобы не задерживать управление. Бан и победа немедленно прерывают очередь. Звук синтезируется Web Audio. При уменьшении движения GIF и анимации отключаются. При недоступности GIF остаётся текст события.

## Размещение
GitHub Pages: ветка main, корневая папка. index.html также открывается локально. На HTTPS манифест и service worker позволяют запуск с главного экрана и кэширование основных файлов. GIF загружаются с Tenor и не доступны офлайн.
